Prepare the USB stick

Download RAW MPC USB Creator Alpha 6 for Mac or Windows. Choose a FAT32 USB stick in the Creator and select Write USB. The Creator writes both supported layouts onto the same stick.

When the Creator says USB ready, eject the stick. Read the alpha warranty notice before testing. If you already have a compatible plugin package, you can add it under USB Files after writing the stick.

To prepare the stick by hand, unzip the loader ZIP and copy its whole RAW plugin folder into VST2 Plugins at the root of the stick.

Open RAW on the MPC

  1. Under Menu → Preferences → Enhancements, turn on Enable Enhancements and External Plugin Support.
  2. Insert the prepared stick. If the legacy USB install prompt appears, dismiss it. Create a Plugin track, then choose RAW MPC Plugin Loader under External Plugins.
  3. Keep the stick plugged in while you use RAW. To keep RAW on the MPC, move it to the internal user drive from Manage Storage.

Install plugins

  1. Connect your MPC to the internet. In RAW, open RAW Catalogue or Open MPC and select a plugin.
  2. Tap Install to to cycle through the writable drives. Choose the internal drive, SD card or USB stick by name.
  3. Tap Install. Save your project in MPC, return to RAW, then tap Continue and Restart Now. After MPC restarts, open External Plugins in an instrument slot or effect insert.

Restart Now applies a pending change and discards any unsaved project edits. Cancel is available on both screens. The same steps apply to updates and removals.

Plugins run from their chosen drive. Leave removable storage connected when you use a plugin installed there. An eligible update stays on the drive where the plugin is already installed. To remove an eligible plugin, choose it in its catalogue and tap Uninstall. RAW saves previous and removed folders in RAW-MPC-Recovery on that drive.

Install from USB Files

Put a complete plugin ZIP or folder for your MPC generation into RAW-MPC-Plugins at the root of the stick. In RAW, open USB Files, select the package and choose the destination before installing.

You can also use a plugin already packaged for Akai’s External Plugin Support directly from a drive. Unzip it and put its entire folder, including plugin.json, directly inside VST2 Plugins at the root of that drive.

Move or remove installed plugins

  1. Tap Manage Storage. Use Prev and Next to select a copy by drive. This copy marks the RAW Loader you opened.
  2. To move the selected copy, tap the destination control until it shows the USB stick, internal drive or SD card you want. Tap Move. If that drive already has the plugin, remove that copy before retrying the move.
  3. To remove a copy, select it and tap Remove. For either action, save your project in MPC, return to RAW, then tap Continue and Restart Now.

RAW puts the original folder in RAW-MPC-Recovery on the source drive. To restore it, first remove any active copy, then put the archived folder back into VST2 Plugins.

Choose RAW MPC Plugin Loader (Legacy) and tap Remove to clear the older Synths installation. RAW backs up the folder and its settings before removing the registration. Projects that used the legacy copy may need RAW re-added from External Plugins.

If you get stuck

If RAW doesn’t appear, check both Enhancements switches, the firmware version and the VST2 Plugins folder at the root of the stick. If a drive is missing from Install to, check it is connected and writable, then tap Refresh.

If MPC lists a plugin but cannot load it from a particular drive, try the internal user drive. Some MPC setups mount removable drives with execution disabled.

Plugins previously installed in Synths may still load in saved projects. To select them in a new track, use a copy packaged for External Plugin Support.

Get support with your MPC model, firmware version and the message on screen.
