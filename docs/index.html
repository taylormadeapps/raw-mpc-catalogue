Set up your MPC

What you’ll need

  • A first-generation standalone MPC. Akai lists the MPC One, One+, Live, Live II, X, X SE, Key 37 and Key 61 in its Gen 1 range.
  • MPC OS 3 with the original USB install prompt. Open MPC documents this USB method through MPC OS 3.9.1.
  • RAW MPC USB Creator Alpha 3 on an Apple silicon Mac running macOS 13 or later or a Windows 10 or 11 x64 PC.
  • A FAT32 USB stick. You can use one that already has projects or samples on it.

Verified with RAW. We installed and opened the loader on an MPC One+ running MPC OS 3.9. Other models and OS versions still need testing with RAW.

To check your MPC OS version, open Menu → Preferences → Info on the MPC. If it meets the requirements above, go straight to making the stick. If you need 3.9.0, see Akai’s firmware updater.

Make the stick on your Mac

This is an early alpha. Back up your projects, samples and settings before trying it. Download the signed and notarised Mac installer and open the .pkg to install the app. The installer includes the warranty notice.

  1. Plug the stick into your Mac and open RAW MPC USB Creator.
  2. Click Choose USB… and pick the stick by name. Click Write USB… and confirm. USB Creator replaces any folder called autorun. Move that folder off the stick first if you want to keep it.
  3. When you see USB ready, eject the stick in Finder.

To install a plugin with the loader on the first run, click Add Packages… and pick the ZIP or the whole plugin folder before you click Write USB…. Once the stick is written, you can add your own plugins to it in Finder.

Make the stick on Windows

Download Windows x64 Alpha 3. Extract the whole ZIP, then open RAW MPC USB Creator.exe from the extracted folder. Keep the files together. This alpha is unsigned and includes a warranty notice.

  1. Plug in a FAT32 USB stick. To bundle plugins, use Add ZIPs… or Add Folder…. Use the original ZIP if a plugin includes executable files.
  2. Click Choose USB… and select the drive itself under This PC. Click Write USB… and confirm. USB Creator replaces the autorun folder on the selected drive.
  3. When you see USB ready, eject the stick in Windows.

Install the loader on your MPC

Already using Alpha 1 or 2? Make a new stick with Alpha 3 and follow the same install steps. The installer updates the existing RAW loader.

  1. Save your project.
  2. Plug in the stick. When the MPC asks to install RAW MPC Plugin Loader, tap Install. Leave the stick plugged in until the MPC screen comes back.
  3. Create a Plugin track and open the instrument browser. Choose RAW MPC Plugin Loader under Ruminant Audio Works.
  4. Look for Loader 0.1.1 and a short build ID at the top of the loader screen. If the update fails, check autorun/INSTALL-RESULT.txt on the stick.

Add plugins from the catalogue

Connect your MPC to the internet and open the loader. Choose RAW Catalogue for Ruminant Audio Works releases or Open MPC for compatible community plugins.

Use Prev or Next to pick a plugin. Save your project, tap Install, then Confirm. When the MPC is back, look for the new plugin in the browser.

Add your own plugins to a USB stick

Once the stick is written, you can copy more plugins to it without running USB Creator again. Use complete plugin ZIPs or folders made for Gen 1 MPC (ARMv7). If you have a loose .so, keep it in its own plugin folder with its plugin-meta.xml and any skin or other files the plugin needs.

  1. Open the stick in Finder or File Explorer. Look for RAW-MPC-Plugins next to autorun. If it’s missing, make that folder.
  2. Copy each plugin ZIP or whole plugin folder into RAW-MPC-Plugins. You can leave ZIPs zipped. Your stick should look something like this:
USB stick/
├── autorun/
└── RAW-MPC-Plugins/
    ├── My Synth.zip
    └── My Effect/
        ├── plugin-meta.xml
        └── my-effect.so
  1. Eject the stick and plug it into your MPC. If you haven’t installed the loader yet, do that first. If the loader is already installed and the MPC asks to install it again, tap Cancel.
  2. Open RAW MPC Plugin Loader and tap USB Files, then Refresh if needed. Use Prev or Next to pick a plugin.
  3. Save your project, tap Install, then Confirm. When the MPC is back, look for the plugin in the browser.

Plugins you copy this way appear under USB Files. To install a plugin with the loader at the first USB prompt, add it in USB Creator when you make the stick.

If you get stuck

USB Creator won’t accept the stick

On Mac, select the stick in Finder and press ⌘I. Look for MS-DOS (FAT32). On Windows, right-click the drive in File Explorer and open Properties. Look for FAT32. Select the drive itself in Choose USB….

The MPC doesn’t show the Install prompt

Open the stick in Finder or File Explorer and look for a folder called autorun. If it’s missing, make the stick again in USB Creator. Check your MPC model and OS against What you’ll need, then try plugging the stick in again.

The loader is missing after the restart

On a Plugin track, look for RAW MPC Plugin Loader under Ruminant Audio Works.

A plugin doesn’t show up

For USB, check that RAW-MPC-Plugins sits next to autorun and contains the complete ZIP or plugin folder for Gen 1 MPC hardware. Tap Refresh. For either online catalogue, check that your MPC is online.

The loader says the plugin is already installed

You can keep using the version you have. If you’re trying to install a newer version, get in touch with the plugin name and the message you see.

Get support if you’re still stuck. Tell us which MPC you have, which version of MPC OS it’s running and what you see on screen.

Akai’s firmware updater

To install 3.9.0 on a Gen 1 MPC, get Akai’s 3.9.0 Gen 1 updater for your computer.

  • Download Akai’s 3.9.0 updater for Mac
  • Download Akai’s 3.9.0 updater for Windows

For other versions, look under Legacy MPC Firmware (Gen 1) in Akai’s Legacy Downloads.

Run the updater

  1. Back up your projects and samples to a separate drive. Plug the MPC into power and connect it directly to your computer with a USB cable.
  2. Open the Akai updater you downloaded. On a Mac, open the ZIP first if it hasn’t already been unpacked.
  3. On the MPC, go to Menu → Preferences → Info. Tap Update, then Switch to Update Mode.
  4. When the MPC is in Update Mode, click Update MPC in Akai’s updater on your computer. Keep the USB cable and power connected while it runs.
  5. When the MPC starts up again, go back to Menu → Preferences → Info and check that it shows 3.9.0.

If the updater won’t run or the MPC doesn’t enter Update Mode, see Akai’s official walkthrough.
